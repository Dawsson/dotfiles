# Product

<!-- impeccable:product-schema 1 -->

## Platform

Native macOS menu bar application.

## Users

Dawson checks connected AI accounts from the MacBook menu bar.

## Product purpose

Show quotas, resets, plans, usage, and spending together, with a simple overview and expandable detail.

## Capabilities and constraints

CLI Proxy API is the account authority, accessed through the existing authenticated Devbox facade. Reuse the existing Devbox API key. No provider login, credential extraction, or independent account collection. Include disabled accounts. Missing plan and price data must remain visibly unknown. Shared proxy spending must not be attributed to an individual account or presented as subscription billing.

## Brand commitments

Use the supplied CodexBar reference for content coverage, with a cleaner native macOS layout.
